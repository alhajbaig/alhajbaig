<br/>

<img align="right" width="340" src="https://media.giphy.com/media/qgQUggAC3Pfv687qPC/giphy.gif" />

I'm **Mirza Alhaj Baig** — a Computer Science Engineering student from **Nagpur, Maharashtra, India**, quietly building my way toward becoming an AI Engineer.

My story started with a single line of Python and a lot of curiosity. That curiosity turned into a mission: build intelligent systems that solve real problems for real people. Not someday. Now.
