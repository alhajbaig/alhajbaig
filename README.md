## 🧠 About Me

I'm a Computer Science student from **Nagpur, India**, building toward a career in **AI and Machine Learning**. I work across the full ML spectrum — from classical models and data pipelines to deep learning architectures and generative AI systems — with Python as my primary language.

My philosophy is simple: **the best way to understand AI is to build with it.** Every project I ship teaches me what no course can. Every failure tells me something true. I'm currently deep in ML and deep learning while actively building **AI Career Mentor**, my flagship project.
