## &ensp;◈&ensp; How I Think

<br/>

> **01 ·** Consistency beats intensity. Show up every single day, no matter what.

> **02 ·** Don't wait until you're ready. You'll never be fully ready. Build anyway.

> **03 ·** The best project is the one that teaches you something completely new.

> **04 ·** Failure is not the opposite of success — it's the fastest route to it.

> **05 ·** Build things for people you'll never meet. That's when it becomes real impact.
